## 1. Format de validation

### 1.1 Qui valide

Une validation est acquise quand **deux** validations se rejoignent :

1. **L'expert humain** — validation de fond, technique et de sécurité.
2. **Master** — validation finale, en langage simple.

L'IA ne se valide pas elle-même. Une recommandation IA n'est pas une validation. Une validation IA seule ne vaut rien dans ce registre.

### 1.2 Les 3 niveaux de lecture (obligatoires)

Toute validation est présentée en **langage simple, en 3 niveaux de lecture** (décision gelée D-10, voir A2) :

| Niveau | Question à laquelle il répond | Longueur visée |
|---|---|---|
| **1 — En une phrase** | Qu'est-ce que ça change pour Master ? | 1 phrase |
| **2 — En bref** | Quels sont les points clés, les choix, les risques ? | Quelques lignes / liste courte |
| **3 — En détail** | Quel est le contenu technique complet ? | Le document complet |

Aucune validation n'est demandée sans ces 3 niveaux. Si le niveau 1 n'est pas compréhensible par Master sans jargon, la validation n'est pas prête.

### 1.3 Statuts possibles

| Statut | Signification |
|---|---|
| Gelé | Validé par l'expert humain + Master. Ne se modifie que par une nouvelle décision de Master (A2). |
| Prêt pour gel | Proposé pour gel. En attente de la décision de Master. |
| En cours | En production / en critique (max 3 cycles, voir A2, D-03). |
| Refusé / à reprendre | Non validé. Les raisons sont consignées. Reprise en nouveau cycle, sur décision de Master. |

### 1.4 Ce qu'une validation doit contenir

Pour être consignée ici, une validation indique :

- l'objet validé (document, livrable, version) ;
- la date ;
- qui a validé (expert humain + Master) ;
- le statut ;
- les réserves éventuelles, le cas échéant.

Aucune validation n'est consignée de mémoire, sans date ni validateur.

## 4. Règles rappelées

- Une validation n'est acquise que par l'expert humain **et** Master.
- Aucune auto-validation par l'IA.
- Format obligatoire : langage simple, 3 niveaux de lecture.
- Après le gel de 05, 06, A5 et des gabarits : STOP documentation (voir A2, D-11). A6 et A7 sont des documents vivants, jamais gelés.
